# 集成副本说明

本目录保存项目根目录 `modulepack.py` 的归档副本，用于记录磁场计算模块与
DAQ 输出层的接口。现有 GUI 仍导入项目根目录中的版本。

正式的安装、标定和使用说明见 [`../README.md`](../README.md)，系统后续设计见
[`../FORCE_CONTROL_MOBILE_WORKSPACE_DESIGN.md`](../FORCE_CONTROL_MOBILE_WORKSPACE_DESIGN.md)。

## 接口约定

- 电压源回调接收样本数，返回形状为 `(3, samples)` 的连续 `float64` 数组。
- 三行数据依次对应 DAQ 通道 `ao0`、`ao1` 和 `ao2`。
- 输出范围为 `-10 V` 至 `10 V`。
- 缓冲区按板载采样时钟连续输出，并在启动前预填。
- 电压源异常会锁存故障，此后持续输出零电压块，直至人工清除故障。

## 维护说明

修改输出层时，应同时检查根目录版本与本归档副本，避免接口行为不一致。
若后续完成 GUI 导入路径迁移，可删除该副本，只保留单一实现。
