## 1. 设计范围

系统采用双时间尺度结构：样品保持固定，三轴线圈磁头随 XY 平台低速移动；
线圈连续产生旋转场，视觉系统和力观测器提供反馈。

```text
目标推进力 F*（实验室坐标系）
        │
        ▼
力语义与可行性检查 ──── 力可行域图谱 / 热状态 / step-out 边界
        │
        ▼
机器人推进模型逆解：F* → 旋转轴 n、旋向 σ、频率 f、场强 B0
        │
        ├──────────────► 慢环：XY 平台重定位 / 联合 MPC
        │                         │
        ▼                         ▼
空间场图：B*(t), p, qstage → 三路线圈电流 → 现有 DAQ 电压输出
        ▲
        │
视觉位置/姿态/转速 + 平台编码器 + 电流/温度 + 可选微力传感器
```

本文所说的“目标力”是目标推进力，不直接等同于机器人所受净力：

- 近似匀强旋转磁场主要施加磁力矩；特殊形状机器人依靠旋转—平移流体耦合产生推进。
- 自由游动达到稳态时，推进项与流体阻力近似平衡，机器人净力接近零。此时更容易直接验证的是速度，而不是非零净力。
- 若目标是机器人接触物体后对其施加的真实力，应定义“接触/堵转推进力”，并用微悬臂、微力计或经验证的力观测器闭环。
- 控制器只接受标定范围和可行域内的请求，并随结果返回预测区间。

在不更换现有三路输出硬件的前提下，本方案能够实现旋转推进控制，但不能像 OctoMag 那样独立合成三维磁梯度力。若以后需要对任意磁矩方向同时实现三维磁力和二维指向控制，应按目标工作区重新做磁源布局与秩分析；相关最少磁源研究给出的通用下限是 8 个独立磁源，因此优先采用经验证的 8 路冗余结构，而不是仅按“6 个目标量”选择 6 路。

第一版按低雷诺数流体中的螺旋或手性结构推进建模。贴壁滚动、摩擦滑移和柔性摆动可沿用控制分层，但需要替换推进模型。V1 的范围限定为平面推进；侧视定位和抗重力能力完备后再扩展到三维。

## 2. 现有系统

项目最初只有“中心点目标旋转场 → 电流 → 三路 DAQ 电压”的安全输出内核。
本轮已在不改变 DAQ 输出契约的前提下加入以下软件骨架：

- 经验证的机器人推进 LUT 和 `F* → (n, sense, f, B0)` 反解；
- 目标力语义、严格可行性拒绝、step-out 裕度和显式边界投影；
- 高斯计 CSV 中心场拟合，以及电压放大器/电流驱动器的逐路模型；
- 二维/三维规则网格场图插值，不允许超出已测区域外推；
- XY 平台接口、逻辑仿真和带迟滞的死区回中策略；
- `MagneticControlSupervisor` 将推进反解与现有电气预检/波形输出串联。

这些模块目前仍是开环、经标定的“推进量指令”。未接入真实机器人数据、相机、
微力传感器或实机 XY 平台，也未将位置相关场图接入每个 DAQ 波形块。因此还不是
真实力闭环或全工作区移动控制系统。

已保留的基础内核包括：

- [`calculator.py`](calculator.py) 接收 `RotatingFieldCommand(axis_xyz, magnitude_T, frequency_hz, rotation_sense)`；`axis_xyz` 是旋转平面法向。
- [`calibration.py`](calibration.py) 使用单点线性模型 `B = C_BI I + B_ambient` 和每路独立 R-L 逆模型。
- [`integration/modulepack.py`](integration/modulepack.py) 的输出契约是连续 `float64` 数组 `(3, samples)`。
- 当前 DAQ 参数为 3 路、100 kS/s、1000 点/块、4 块预填、AO ±10 V；因此一个波形块是 10 ms，已排队数据约对应 40 ms 延迟。
- 现有代码已经具备相位连续命令切换、峰值/RMS 预检、自动延长过渡、停机回零和故障锁存，这些能力必须保留。
- 当前唯一配置 [`magnetic_control_config.example.json`](magnetic_control_config.example.json) 是未验证占位值，不能据此宣称任何真实场强、频率或力性能。
- `integration/modulepack.py` 是归档副本，现有 GUI 实际导入项目根目录的 `modulepack.py`；后续不能让两份实现继续漂移。

后续模块沿用以下约定：

1. 内部 SI 单位：N、m、m/s、T、A、V、Hz、Pa·s、K/°C。
2. 三路磁场输出仍通过 `generate_voltage_block(samples) -> (3, samples)` 接入。
3. XY 平台使用独立数字接口，不占用现有三路 AO。
4. 继续强制 `verified`、满秩、条件数、电流、电压、频率和安全过渡检查。
5. 外环显式处理相机、计算、平台和约 40 ms DAQ 队列延迟，所有状态必须带时间戳。

## 3. MiniMag 与 OctoMag

| 项目 | MiniMag | OctoMag | 对本项目的意义 |
|---|---|---|---|
| 结构 | 8 个静止软磁芯线圈，单半球、开放、紧凑 | 8 个静止软磁芯线圈，两层近半球布置 | 两者都不是当前三路线圈的直接替换模型 |
| 控制能力 | 5-DOF：3D 力 + 2D 指向 | 5-DOF：3D 力 + 2D 指向 | 5-DOF 不等于绕磁矩轴可控的 6-DOF |
| 求解 | 单线圈场图线性叠加，伪逆分配最小二范数电流 | 同左，使用场/力或力矩/力 actuation matrix | 多线圈冗余分配成熟，裸伪逆不是创新 |
| 工作区口径 | 约 10 mm 直径磁工作区；样品放置区更大 | 常用约 20 mm 级磁工作区 | “能放下样品”不等于整块区域都能保证性能 |
| 旋转推进 | 已演示螺旋推进，并叠加小梯度作轨迹修正 | 论文明确讨论旋转推进与梯度力可叠加 | “旋转推进 + 梯度修正”本身不是新点 |
| 动态 | 小型系统可达较高动态；2 kHz 是响应口径，不代表满幅输出 | 大线圈约 89 mH，动态明显较慢 | 必须按场强/电流实测幅频，而非引用标称频率 |
| 空间模型 | 大范围应使用实测/FEM 网格，不应只用中心单点模型 | 同左 | 平台移动后必须使用位置相关场图 |

OctoMag 的一般模型是：

```text
τ = m × B
Fmag = (m · ∇)B
[τ; Fmag] = Aτ,F(m, p) i
```

八路结构可用伪逆或约束优化求电流。当前三路系统可以合成 `B`，但不能同时独立指定 `∇B`。第一阶段控制的是机器人形状耦合产生的推进力，而不是直接磁梯度力。

## 4. 力的定义

### 4.1 控制模式

API 使用以下三种独立模式：

1. `ESTIMATED_PROPULSIVE_COMPONENT`：旋转产生的轴向推进项估计，单位 N。适用于自由游动，但它不是机器人净力。
2. `BLOCKED_THRUST`：机器人轴向速度近似为零且与已知对象接触时，对外可施加的轴向力，单位 N。必须由微力实验标定。
3. `FREE_SWIM_VELOCITY`：自由游动速度，单位 m/s。若当前没有可靠力传感，这是第一版闭环最稳妥的实际输出。

论文或演示中，只有第 2 种且接触力被实时测量/可靠观测并纳入反馈时，才可以称为“真实输出力闭环”；仅做堵转力离线标定再开环发频率，仍然不是力闭环。第 1 种应称为“估计推进力闭环”。进入 `BLOCKED_THRUST` 还必须确认接触对象、允许的接触法向、夹具/载荷身份和实时接触状态，并确认机器人仍在受控旋转而不是机械卡死；仅由视觉看到 `v≈0` 不能证明接触力可观测。

### 4.2 低雷诺数推进模型

沿机器人螺旋轴的简化阻力关系可写成：

```text
[Fh]   [A  C] [v]
[τh] = -[C  D] [ωr]
```

`A、C、D` 由几何、黏度、壁距和载荷决定；符号由坐标和手性定义。于是：

- 堵转 `v = 0` 时，机器人受到的流体反力（以及它对障碍物/流体施加的反向力）幅值近似与实际转速 `ωr` 成正比。
- 自由游动且无其他轴向外力时，`v ≈ -(C/A)ωr`。
- 同步区内 `ωr ≈ 2πf`；超过 step-out 后，机器人不再跟随旋转场，简单线性关系失效。

工程上不用未经验证的理想公式直接发命令，而建立带不确定度的实验模型：

```text
Fprop = sχ · σ · g(B0, f, η, h, load, robot_id, temperature) · n + Flat
```

其中：

- `n`：右手旋转轴；
- `σ ∈ {-1,+1}`：现有 `rotation_sense`；
- `sχ ∈ {-1,+1}`：机器人手性和磁化方向共同决定的实测推进符号；
- `g ≥ 0`：轴向推进模型；
- `Flat`：壁面、重力、wobble 等造成的横向分量。

实际线圈不可能在整个区域绝对匀强，机器人还会受到残余直接磁力 `Fmag = (m·∇)B`。因此对外作用或自由游动动力学应使用 `Fprop + Fmag + Fdisturbance`；三路线圈不能任意消除 `Fmag`，第一版只能把残余梯度纳入空间标定，并把 `||Fmag||` 或方向偏差超过阈值的位置排除在有效区外。若必须在大范围内独立消除/指定该分量，就要升级冗余线圈结构。

给定非零目标 `F*`，控制器将旋转轴 `n` 与 `B0、f` 一起作为推进模型逆解变量，并在物理等价的轴/旋向表示中选择过渡最平滑的一组。只有在独立验证 `Flat` 和残余 `Fmag` 可忽略的轴向近似下，才可直接取 `n=F*/||F*||`；否则应通过完整矢量模型补偿方向偏差。目标为零时必须调用安全 `stop()`，不能构造零幅值或零频率的 `RotatingFieldCommand`，因为现有命令类不接受这两个值。

### 4.3 场强和频率

对硬磁螺旋机器人，在同步区内，推进力/速度通常主要随频率变化；提高 `B0` 的主要作用是增加磁矩和 step-out 裕度，而不是无限提高同步区推进力。因此建议：

- 频率 `f` 主要调力幅；
- 场强 `B0` 取维持同步和方向稳定所需的最小安全值，以降低电流和发热；
- 在线监测机器人相对磁场的相位滞后、转速或速度，接近 step-out 时先降频；
- 初始运行上限取 step-out 单侧预测或容忍下界的 70%–80%，起始值取 75%；最终比例由风险分析和实验确定。

力逆解可表述为：

```text
min(B0,f)  (g(B0,f,z) - ||F*||)^2
           + λP · electrical_power
           + λΔ · command_slew

s.t.       f <= 0.75 · f_stepout_lower(B0,z)
           current / RMS / voltage / temperature limits
           force uncertainty <= allowed uncertainty
```

`z` 汇总黏度、壁距、载荷、温度和机器人个体状态。不可行时默认拒绝命令并返回原因；只有调用方明确选择 `project_to_feasible=True` 时，才投影到最近可行力，并同时返回实际预计值，禁止静默饱和。

## 5. 机械与传感系统

### 5.1 机械布置

基线方案保持样品、微流道或组织模型不动，将以下部件安装在同一 XY 运动横梁上：

- 三轴线圈组件；
- 线圈局部坐标标志；
- 可选高倍率局部相机或反射镜；
- 可选局部 Hall 探头；
- 冷却歧管和温度传感器。

功放、电源和实时控制机保持静止，通过拖链走线。理由是移动样品会直接扰动液体并制造与机器人推进相混淆的流场。

该方案要求线圈具有开放通道，且移动质量和碰撞间隙允许。若封闭式磁头无法安全平移，可改用“固定磁头 + 密封样品 XY 台”：平台换区后等待液体和图像稳定，再恢复力控制。这种方式适合大尺寸微流控芯片扫描，不适合平台运动期间连续施力。最终方案按质量、振动、流体扰动和可达区进行机械评审。

XY 平台应具备：

- 双轴闭环编码器、原点、正负硬限位和软件限位；
- 非磁性工作区材料；电机尽量远离磁工作区；
- 可记录的最大速度、加速度、重复定位精度和跟随误差；
- 足以承载线圈、冷却和相机的刚度；
- 限制 jerk 的轨迹发生器，避免显微图像抖动和流体扰动；
- 独立急停和看门狗；丢失平台状态时磁场必须安全回零。

平台选型需要线圈质量、全局工作范围和允许力纹波作为输入。基本关系为：

```text
stage_travel >= desired_global_workspace - guaranteed_local_workspace_overlap
stage_error  << local force-map spatial scale
stage_load   >= moving_head_mass with acceleration and cable-force margin
```

### 5.2 视觉系统

优先级从低成本到高可靠性：

1. 单个固定广角顶视相机：适合第一阶段二维验证，但微机器人像素分辨率可能不足。
2. 随磁头移动的高倍率相机 + 平台编码器 + 样品全局标志：局部分辨率高，但依赖外参和平台误差。
3. 固定全局相机 + 随动高倍率相机：研究版配置；前者负责全局重定位，后者负责局部姿态、转速和相位跟踪。
4. 若要验证任意三维力方向，增加侧视/双目/数字全息；只有顶视相机时，第一阶段应将承诺限制为平面力。

所有观测必须包含采样时间而不是处理完成时间。控制器要按每一状态量的时间戳传播到预计生效时刻；可将其近似写为 `t_apply ≈ t_command + compute_latency + queued_DAQ_latency + actuator_latency`，不能把已经体现在图像时间戳里的相机延迟再重复相加。

### 5.3 电气与安全传感

闭环运行需要以下测量：

- 每路线圈实际电流采样；
- 每路线圈温度、功放故障、冷却流量；
- 平台编码器、限位和急停；
- 至少一个可移走/校准用三轴 Hall 探头；
- 接触力研究所需的微悬臂或微力计。

现有软件 R-L 模型假定每路独立、线性、定常。如果实际功放是闭环电流驱动器，或者存在互感、限流、饱和与频率相关增益，应改用实测 MIMO 频响/电流闭环，不能继续把占位 R-L 参数当成实机模型。软磁芯、涡流、温度以及平台电机/金属也可能改变幅值和相位，所以旋转场圆度应由位置、频率、温度和平台位姿相关的复频响或等价状态空间模型验证，而不只看 DC 场矩阵。

## 6. 坐标系和空间场模型

至少定义四个右手坐标系：

- `{G}`：固定在样品上的全局实验室坐标系；目标力在此表达。
- `{C}`：固定在线圈磁头上的局部坐标系；现有 `axis_xyz` 应解释为该坐标系中的旋转轴。
- `{S}`：XY 平台坐标系。
- `{K}`：相机坐标系；多相机分别编号。

由平台编码器和外参得到 `T_GC(qstage)`。机器人全局位置 `p_G` 转换成线圈局部位置：

```text
p_C = T_CG(qstage) · p_G
d_C = R_CG(qstage) · F*_G / ||F*_G||
```

`d_C` 是期望力方向，不自动等于旋转轴。若轴向模型已验证，可取 `n_C≈d_C`；若存在显著 `Flat`、重力、壁面效应或残余梯度力，`force_allocator` 应求解 `n_C、B0、f、σ`，使预测总力方向逼近 `d_C`。

低频/准静态空间场模型可写成：

```text
B_G(p_G, q, i) = R_GC(q) · C_BI(p_C) · i + Bambient_G(p_G, q)
```

旋转场工作频率下应使用复频响（或等价状态空间模型）：

```text
Bhat_G = R_GC(q) · H_BI(p_C, ω, T, q) · ihat + Bambient_hat_G
```

`C_BI(p_C)` 是上述模型在准静态条件下的特例；空间图应来自实测网格或经实测校正的 FEM，再做连续插值。`H_BI` 还要表征通道交叉耦合、幅相误差、温度和平台位姿影响。不能把中心 `3×3` 矩阵简单复制到整个平台行程。还应测量：

- 场幅和方向误差；
- 机器人尺度内的场均匀度与残余梯度；
- 矩阵秩和条件数；
- 平台电机、金属结构和位姿造成的背景场变化；
- 电流、频率和温度引起的增益变化。

第一版可用二维 `(x_C,y_C)` 网格；三维控制再扩为 `(x_C,y_C,z_C)`。分区模型必须使用连续插值和重叠区融合，不能在区域边界硬切矩阵。

这里需要一次底层重构：当前 `RotatingFieldCalculator` 在构造时缓存固定中心点逆矩阵，`RotatingFieldCommand` 也没有位置和生效时间，因此仅新增 `spatial_field_map.py` 并不会改变实际输出。波形调度器应为每个预计施加的块传入目标场、`H_BI/C_BI`、背景场、平台位姿和温度，或给计算器注入带时间戳的场图 provider；固定中心 provider 仅作为向后兼容模式。

## 7. 有效区域与力可行域

本项目不再用一个几何圆简单表示有效区域。对每个位置、方向和环境状态，定义可实现推进力集合：

```text
Fset(p_C, θ, z, thermal_state)
```

局部有效区域 `Wlocal` 中的点必须同时满足：

1. 工作频率下的 `H_BI(p_C,ω,T,q)`（准静态时为 `C_BI`）满秩且条件数低于验证阈值；
2. 机器人尺寸范围内场均匀度满足要求；
3. 对所需方向存在不超电流/电压/温度的旋转场；
4. `f` 保持在经校准的 step-out 单侧预测/容忍下界以下；
5. 力幅和方向的联合预测下界仍能以预定覆盖率满足请求；
6. 视觉可见、平台无碰撞、所有状态新鲜。

离线生成以下极坐标图：

```text
Fmax_lower(p_C, θ, z) = calibrated_one_sided_lower_quantile(data, model)
```

不能把均值置信区间或未经校准的 `mean-kσ` 当成“单次命令 95% 保证”。实现时应明确总体、机器人个体和环境分层，采用单侧预测区间/容忍区间或校准后的保序方法，并对力幅与方向使用联合 chance constraint；全图还要在独立数据上报告覆盖率，处理大量位置查询带来的多重比较问题。

运行时返回：

- 是否可行；
- 预计推进力向量；
- 经校准的预测/容忍区间及其目标覆盖率；
- 电流/电压/热裕度；
- step-out 裕度；
- 方向误差上界；
- 若不可行，最近可行命令和具体原因。

这比仅报告“磁场工作区直径”更符合用户真正需要的能力。

## 8. 控制结构

### 8.1 旋转场与推进力控制

初始控制速率如下，最终值以硬件测试为准：

| 层 | 初始频率 | 作用 |
|---|---:|---|
| DAQ 波形 | 100 kS/s（保持现状） | 相位连续电压输出 |
| 波形块更新 | 100 Hz（10 ms/块） | 更新场轴、频率和幅值 |
| 电流/场监测 | 1–10 kHz，视采集硬件 | 检测功放、电流和饱和异常 |
| 视觉/力观测 | 30–100 Hz | 位姿、转速、相位滞后、力估计 |
| 力分配器 | 30–100 Hz | `F* → n,σ,f,B0` |
| 平台规划 | 5–20 Hz | 重定位和联合优化 |

这些速率是规划目标，不是当前接口已经支持的能力。现有计算器默认命令过渡约 `0.25 s`；若分配器以 30–100 Hz 反复调用 `set_command()`，每次都会重建 smoothstep，可能长期追不上目标。应把“外环重规划”和“载波连续生成”解耦：分配器提交带生效采样号的稀疏轨迹节点，波形调度器在节点之间连续插值且不重启既有过渡；只有显式取消/急停才截断轨迹。

快环流程：

1. 检查命令语义、单位、时间戳和目标位置。
2. 查询当前位置的力可行域；拒绝或显式投影不可行命令。
3. 根据机器人手性选择轴/旋向，避免不必要的 180° 表示跳变。
4. 用推进模型反求 `f、B0`，满足 step-out、热和电气约束。
5. 根据 DAQ 的采样时钟、已确认队列深度和平台轨迹，预测每个块真正生效时的 `p_C`，查询空间频响。
6. 合成目标旋转场并求线圈电流；三路版本使用位置/频率相关逆模型或约束最小二乘。
7. 继续由现有 R-L/后续 MIMO 逆模型生成 `(3,N)` 电压块。
8. 观测机器人转速、场—机器人相位差和速度，在线修正推进模型尺度。

当前 `modulepack` 只调用 `source(samples)`，没有硬件采样计数、块序号、已排队样本数、实际施加时间或 ACK；“约 40 ms”只是由四个预填块得到的名义估计，不能作为精确补偿。底层应增加以 DAQ sample clock 为基准的 `block_sequence、first_sample_index、planned_apply_time、actual_queue_depth` 遥测，并实测从命令、DAQ、电流到磁场的总延迟和抖动。若硬件/API 无法给出实际 ACK，控制器必须把它当有界不确定延迟，而不是伪造精确 `t_apply`。

### 8.2 XY 平台控制

第一版先实现容易验证的“死区回中”策略：

- 机器人位于局部内区时平台静止；
- 越过触发边界后，平台以限速、限加速度轨迹把机器人重新置于局部高性能区；
- 移动期间根据平台实测位姿连续更新场图，旋转场不中断；
- 回到停止边界后平台停稳，使用迟滞避免来回抖动。

死区阈值可先取有效半径的 `0.55` 作为触发点、`0.20` 作为停止点，之后根据实验调整。

后续版本采用快线圈—慢 XY 平台联合预测控制（N1）：

```text
min over qstage, B0, f
Σ (Fpred - F*)ᵀ QF (Fpred - F*)
  + λP · iᵀRi
  + λT · thermal_cost
  + λv · ||Δq||²
  + λa · ||Δ²q||²
  - λm · force_margin(p_C, direction)

s.t. stage position / speed / acceleration / collision limits
     current / voltage / RMS / temperature limits
     step-out lower-bound margin
     visibility and field-map validity
```

平台控制器维持目标方向上的可实现推进力裕度，同时约束发热和移动频率。研究重点是目标函数和跨局部区域的力连续性，而不是 XY 平台本身。

### 8.3 跨区连续性

平台运动时使用连续插值，避免硬切换局部标定表。配套措施包括：

- 连续场图插值；
- 基于预计生效时刻的位姿前馈；
- `B0、f、n` 的 slew 限制；
- 力模型/场模型置信度加权融合；
- 平台加速度前馈和图像运动补偿；
- 过渡区内以力纹波而不是位置误差作为首要约束。

N1 的验证内容是：跨越多个局部工作区时，推进力方向不翻转、幅值不出现明显凹陷，同时满足 step-out 和热约束。

## 9. 推进力观测与模型更新

离线标定无法覆盖黏度、壁距、载荷和机器人个体差异，因此采用物理先验与在线尺度修正相结合的模型：

```text
Fmean = gphysics(B0, f, geometry, η, h) + gresidual(features)
```

可选实现顺序：

1. 单调分段样条/LUT：最容易验证，禁止在 step-out 外外推。
2. RLS/EKF：在线估计推进系数、拖曳系数和扰动项。
3. 带单调/物理约束的高斯过程或小型网络：输出均值和不确定度；数据充分后再引入。

观测输入包括视觉速度、姿态、实际转速、相位滞后、`B0/f`、壁距估计、温度和平台位姿。仅凭自由游动速度无法唯一得到真实接触力，除非拖曳模型已经独立验证。

N2 是环境自适应的旋转螺旋推进力闭环。受控量为堵转或接触推进力，在线模型处理黏度、壁距、载荷和机器人个体差异，并利用相位滞后估计 step-out 裕度。自适应微力跟踪、移动微机器人的实时力反馈、局部流动感知和在线运动补偿已有先例；本项目的区别在于把旋转螺旋推进、环境与载荷辨识、失步判断以及独立微力反馈放入同一闭环。

N3 是带校准下界的全局力可行域图。它把空间场误差、推进模型不确定度、温升和 step-out 合并到 `Fmax_lower`，供平台选择局部工作点。磁场工作区、定位误差和热约束本身已有较多研究，差异主要在旋转推进模型的不确定度传播及其与平台决策的结合。

## 11. 标定流程

### 11.1 电气标定

1. 实测功放命令—线圈电流的 DC 增益、频响、限流和饱和。
2. 测每路线圈 R/L；若存在显著互感，拟合 MIMO 模型。
3. 确定不同频率/幅值下的电流和 DAQ 电压可行域。
4. 实测滑动 RMS、I²t、稳态温升和冷却故障响应。
5. 生成真实 `magnetic_control_config.json`，审查后才允许 `verified: true`。

### 11.2 空间场图

1. 平台回零，标定 `{S}->{G}` 和 `{C}->{S}`。
2. 在局部网格逐路线圈施加正负多级电流，三轴 Hall 测量 `B`。
3. 对每个点先拟合准静态 `C_BI(p)`，再在工作频带拟合 `H_BI(p,ω,T,q)` 或等价状态空间模型，并记录背景场、残差和条件数。
4. 在独立验证点测试任意方向的旋转场幅值、圆度和方向误差。
5. 平台走遍计划行程，测电机通断、位置和金属结构对背景场的影响。

### 11.3 机器人推进与 step-out

每个 `robot_id × 流体 × 温度 × 壁距 × 载荷` 至少执行：

1. 两个旋向、多个 `B0` 的频率上扫和下扫，识别迟滞。
2. 从视频得到实际转速、速度、wobble 和场—机器人相位差。
3. 用微悬臂/微力计进行堵转推力标定。
4. 在 step-out 前拟合单调模型，在其后仅用于检测，禁止正常控制外推。
5. 在局部网格重复关键点，分离机器人模型与空间场误差。
6. 留出独立机器人、黏度和壁距组作盲测。

### 11.4 平台与视觉外参

1. 标定平台轴的尺度、正交度、回差和重复性。
2. 标定相机内参和 `{K}->{G}`；随动相机还需手眼标定。
3. 测平台运动时图像延迟、振动和视场丢失条件。
4. 使用样品固定标志验证跨平台行程的全局位置一致性。

## 12. 安全策略

现有峰值/RMS 检查需要扩展为系统级安全监督：

- 滑动 RMS、I²t、线圈温度、功放温度、冷却流量；
- 实际电流与命令电流偏差；
- 平台软/硬限位、跟随误差、碰撞区和编码器新鲜度；
- 视觉跟踪置信度、机器人离开有效区、相位锁定丢失；
- step-out、wobble、模型外推和力不确定度过大；
- DAQ 队列延迟或生成回调超时；
- 用户急停、功放硬件使能和独立看门狗。

安全链不能只靠 `supervisor` 轮询。平台驱动器和线圈功放应共享独立的硬件安全回路：急停/门禁/看门狗断开功放使能并触发平台安全停止；功放侧提供适合感性负载的续流/能量钳位路径。分别实测“检测到故障→禁止新输出”“功放禁能→线圈电流降到安全阈值”“平台→安全停稳”的最坏时间，并据此设置碰撞距离和 DAQ 队列上限。

故障分为三级：

| 等级 | 示例 | 动作 |
|---|---|---|
| 限制 | 接近 step-out、热裕度下降 | 降频/降幅，保持跟踪 |
| 受控停止 | 视觉短时丢失、模型置信度不足 | 冻结平台，线圈平滑回零 |
| 紧急降能 | 过流、功放故障、平台碰撞风险 | 硬件禁能并制动平台 |

视觉丢失时是否能短暂保持最后命令必须由应用风险决定；默认安全策略应是停止推进并回零，而不是在盲态继续施力。

当前 `modulepack` 故障后立即输出全零块，但已排队波形仍会延迟生效，DAQ 0 V 也不等于感性线圈电流立即为零，而且它不会自动停止 XY 平台。这只是软件降能请求，不是安全联锁；必须用实机验证功放关断、续流和线圈电流衰减，并配置共同硬件禁能链与急停。

## 13. 研究定位

以下判断是截至 2026-08-12 的工程文献检索结论，不是专利自由实施（FTO）或法律意见。

### 13.1 已有工作覆盖的内容

- 输入方向/大小后自动生成旋转场：已有期望速度到朝向/频率的逆控制。
- 用螺旋或特殊形状把旋转变为推进：1990 年代已有，2009 年后大量微纳机器人工作。
- 优化螺旋形状以提高速度/推力：已有连续形状优化和高增益新尾形研究。
- 用伪逆/最小电流把目标场或力分配到多线圈：MiniMag、OctoMag 及后续约束优化已覆盖。
- 在线圈系统下增加 XY 平台或机械臂扩大工作区：BigMag、DeltaMag、ARMM、Yang 2021、MEMA 2025 等已有。
- 旋转推进同时叠加梯度修正：MiniMag 已演示。

### 13.2 拟研究内容

| 编号 | 研究内容 | 现阶段判断 | 验证重点 |
|---|---|---:|---|
| N1 | 快线圈—慢 XY 平台联合 MPC，以螺旋推进力裕度和跨区力连续性而不是仅位置回中为目标 | 中 | 相比位置—电流联合优化、几何调度、固定阵列和阈值回中，显著降低跨区力纹波、能耗或温升 |
| N2 | 环境自适应的旋转螺旋堵转/接触推进力闭环，联合更新环境、载荷、个体与 step-out | 中 | 区别于一般微力跟踪和螺旋运动补偿；用独立微力真值证明，不只是速度/位置闭环 |
| N3 | 含推进不确定度、热约束和 step-out 置信裕度的全局力可行域图谱，并驱动平台主动选位 | 弱到中 | 区别于已有 workspace、敏感度和热约束；验证不确定度传播与覆盖率 |
| N4 | 机器人形状与“可控/可辨识性”协同优化，而不只最大化峰值推力 | 中 | 证明更单调的力—频率映射、更低 wobble、更宽安全区和更强环境鲁棒性 |
| N5 | 若升级冗余线圈：利用零空间抑制非期望梯度/横向漂移并作热均衡 | 弱到中 | 单独不新，必须作为 N1/N2 的支撑机制 |

论文主线可由 N1 和 N2 组成，N3 用于描述系统可行域，N4 留作机器人设计方向。单个子项目前都不足以单独主张首创。

拟研究的问题可表述为：面向旋转驱动手性微机器人的不确定推进力控制，建立包含实验不确定度、step-out 和热约束的全局力可行域；通过快线圈—慢平台联合预测控制，维持跨局部工作区的推进力矢量连续性。

这个表述仍需正式专利检索以及对照实验后才能使用“首次”。

## 14. 实施阶段

### M0：需求冻结

必须先量化：机器人尺寸/材料/磁矩/手性、介质与黏度范围、壁距、目标力范围、局部/全局空间、允许误差、最大温度和是否接触物体。

交付：`system_requirements.md`、风险清单、力语义确认。

### M1：固定中心的开环推进力映射

- 软件骨架已完成：高斯计 CSV 拟合、机器人 LUT、严格可行性返回、
  step-out 安全裕度和 `RotatingFieldCalculator` 接入；
- 待完成真实电气与中心场标定；
- 待建立具体机器人的 `B0/f → 转速/速度/堵转力` 数据。

退出条件：独立测试集上力模型误差和预测/容忍区间覆盖率达到预设门槛。

### M2：固定磁头的视觉/力闭环

- 引入时间戳、延迟补偿、机器人状态估计；
- 扩展当前 `PropulsionCommand`，加入时间戳、TTL、作用点、误差限制和接触法向；
- 完成定方向阶跃、变方向和扰动实验。

退出条件：固定中心真实力或估计推进力稳定跟踪，且不进入 step-out。

### M3：局部空间场图

- 准静态二维/三维规则网格插值和域外拒绝已完成；
- 待用 Hall 探头建立真实场图，并在工作频带辨识 `H_BI(p,ω,T,q)`；
- 待加入空间模型不确定度与矩阵质量标记；
- 构建第一版局部力可行域。

退出条件：整个 `Wlocal` 的场/力误差和方向误差均满足门槛。

### M4：XY 平台与死区回中

- 平台抽象接口、逻辑仿真、行程检查和带迟滞的死区回中已完成；
- 待接入真实平台驱动、回零、硬限位、手眼标定和联锁；
- 待用实机死区策略连续跨越至少三个局部有效区宽度；
- 运动过程中连续更新场模型。

退出条件：无场方向翻转、无跟踪丢失、跨区力纹波受控。

### M5：联合 MPC 与在线自适应

- 实现 N1 联合优化；
- 实现 N2 在线推进模型更新；
- 生成 N3 全局校准下界力图谱；
- 与三个基线做完整消融实验。

## 15. 验证方法

对照组：

1. 固定线圈 + 中心单点模型；
2. 固定/移动线圈 + 阈值回中；
3. 联合 MPC；
4. 联合 MPC + 在线力辨识。

变量：

- 目标方向和力幅；
- 位置及跨区路径；
- 至少三档黏度、三档壁距；
- 有/无载荷；
- 多个机器人个体；
- 冷机与热稳态；
- 平台静止与移动。

以下数值仅作为第一轮实验目标，不代表当前性能：

- 标定区内旋转场幅值误差 ≤ 5%，方向误差 ≤ 3°；
- 高于力传感分辨率 5 倍的命令，力幅 RMSE ≤ 10%–15%，方向误差 ≤ 5°；
- 跨区峰峰力纹波 ≤ 10%，且无方向反转；
- 正常控制始终低于 step-out 经校准单侧预测/容忍下界的 80%；
- 95% 预测区间覆盖率与标称覆盖率偏差 ≤ 5 个百分点；
- 全程满足实测温度、电流、电压、平台和视觉联锁；
- 报告全局可用面积、单位面积能耗、最大连续运行时间，而不只报告中心峰值。

若微力真值暂不可用，应把验收项和界面名称降级为“估计推进力”，同时报告自由游动速度，不得用速度误差替代真实力误差。
